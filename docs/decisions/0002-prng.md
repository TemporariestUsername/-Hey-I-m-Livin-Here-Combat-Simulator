# ADR 0002: PRNG and named substreams

- **Status:** accepted
- **Decision date:** 2026-07-29
- **Owner:** engine maintainers
- **Risk:** high

## Context

A single random sequence couples unrelated mechanics: adding one sensing draw can otherwise change later contact, morale, or policy outcomes.

## Decision

Use PCG32 with explicit unsigned 64-bit `bigint` arithmetic. A scenario supplies one non-negative safe-integer seed. Stable numeric stream IDs derive independent streams named `sensing`, `movement`, `contact`, `morale`, and `policy`; allocation or call order never assigns stream identity.

`nextUint32()` is the compatibility primitive. `nextFloat()` divides that unsigned integer by `2^32`. Persisted floating samples are normalized by ADR 0005, while decision logic may use the unrounded draw.

Engine 0.4 continuations serialize each stream as a lowercase, zero-padded 16-hex-digit state, an odd 16-hex-digit increment, and a bounded draw count. Restoration assigns those values directly after structural validation; it does not reseed or consume a hidden draw. The continuation checksum covers every stream snapshot.

## Alternatives considered

`Math.random()` was rejected because it is ambient, unseeded state. A single seeded stream was rejected because it couples mechanics. Cryptographic randomness was rejected because unpredictability is not required and reproducible substreams are.

## Consequences and evidence

Every named stream has a published golden vector. A test deliberately consumes extra contact draws and proves the policy vector is unchanged. Snapshot/restore tests prove the next 16 values are exact, malformed increments fail closed, every pre-terminal pulse resumes byte-identically, and tampering fails the continuation checksum. Changing PCG32, seed expansion, stream IDs, snapshot encoding, or float conversion is an engine compatibility break. Evidence is in `tests/phase-zero.test.ts`.

## Review trigger

Review before adding a stream name, changing seed width or snapshot encoding, or permitting external policy code to request randomness.
