# ADR 0002: PRNG and named substreams

- **Status:** accepted
- **Date:** 2026-07-29
- **Owner:** engine maintainers
- **Risk:** high

## Decision

Use PCG32 with unsigned 64-bit `bigint` state and independently seeded named streams for sensing, movement, contact, morale, and policy decisions. Seeds are non-negative safe integers. Stream identifiers are stable data, not allocation order.

## Consequence

Adding a draw to one mechanic cannot perturb another mechanic. Published golden vectors detect runtime or algorithm drift. Changing the algorithm or stream assignment is a versioned compatibility break.
